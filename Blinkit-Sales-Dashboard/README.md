Blinkit Sales Analysis Dashboard
Project Overview
This Power BI dashboard analyzes Blinkit's sales performance, outlet trends, customer ratings, item categories, and outlet performance.
Project Objectives
•	Analyze overall sales performance
•	Monitor outlet-wise sales and ratings
•	Identify top-performing item categories
•	Compare outlet sizes and locations
•	Build an interactive Power BI dashboard
Tools & Technologies
•	Power BI
•	Excel/CSV
•	Power Query
•	DAX
•	Data Modeling
Dashboard KPIs
•	Total Sales: $1.20M
•	Average Sales: $141
•	Number of Items: 8,523
•	Average Rating: 3.9
Key Insights
•	Tier 3 outlets generated the highest sales.
•	Medium-sized outlets contributed the largest revenue share.
•	Fruits and Snack Foods are among the best-selling categories.
•	Supermarket Type1 recorded the highest sales.
•	Average customer rating is 3.9/5.
