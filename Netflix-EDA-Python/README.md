# 📊 Netflix Exploratory Data Analysis (EDA)

## Project Overview
Performed Exploratory Data Analysis (EDA) on the Netflix Movies and TV Shows dataset using Python to identify trends, clean data, and generate business insights.

## Tools Used
- Python
- Pandas
- NumPy
- Matplotlib
- Jupyter Notebook

## Analysis Performed
- Data Cleaning
- Missing Value Handling
- Duplicate Removal
- Exploratory Data Analysis
- Data Visualization

## Key Insights
- Movies dominate the Netflix catalog.
- USA has the highest number of titles.
- Drama and International Movies are the most popular genres.
- Netflix content increased rapidly after 2015.
