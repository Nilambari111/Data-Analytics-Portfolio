# 👨‍💼 HR Analytics Dashboard

## 📌 Project Overview

This Power BI dashboard provides a comprehensive analysis of HR data to help organizations monitor workforce trends, employee attrition, demographics, and performance metrics. The dashboard enables HR teams to make data-driven decisions for improving employee retention and workforce planning.

---

## 🎯 Project Objectives

- Analyze employee attrition trends
- Monitor workforce demographics
- Identify high attrition departments and job roles
- Track key HR performance metrics
- Build an interactive HR Analytics Dashboard

---

## 🛠 Tools & Technologies

- Power BI
- Power Query
- DAX
- Microsoft Excel
- Data Modeling

---

## 📈 Dashboard KPIs

| KPI | Description |
|------|-------------|
| 👥 Total Employees | Total number of employees |
| ✅ Active Employees | Currently active employees |
| ❌ Attrition Count | Employees who left the organization |
| 📉 Attrition Rate | Percentage of employee attrition |
| 🎂 Average Age | Average employee age |
| 💰 Average Salary | Average employee salary |

---

## 📊 Dashboard Features

- Employee Overview
- Department-wise Employee Analysis
- Gender Distribution
- Attrition Analysis
- Job Role Analysis
- Education Field Analysis
- Employee Age Distribution
- Employee Count by Department
- Interactive Filters and Slicers

---

## 💡 Key Insights

- Identified departments with the highest attrition.
- Compared employee distribution across different departments and job roles.
- Analyzed workforce demographics based on age and gender.
- Monitored employee attrition trends.
- Tracked overall HR performance using KPI cards.
